## Guarded operation

`node --import tsx --env-file=.env.local scripts/promote-miopages-focus.ts` prints
the plan. `--apply` executes the authorized transition in one transaction with
table locks, explicit target ownership, exact previous-row predicates and complete
postconditions. Unexpected MioPages, other-customer or migration state refuses with
no repair mode. First/final-write failures roll back all rows. Immutable logo bytes
may remain after rollback but no Asset/usage row survives. Exact rerun writes nothing.
No migration is needed and the nine-row migration journal is untouched.

Capture/preparation scripts are one-time pre-promotion review tools; do not regenerate
the frozen file or initial receipt to synchronize future customer edits. Preview
preparation recognizes the exact authorized promoted graph, then uses the frozen
historical initial graph only inside new disposable schemas, keeping prior pinned
experiments reproducible without resetting canonical state.

`scripts/verify-miopages-promotion.ts` compares the frozen full baseline against
current real state and writes ignored before/after evidence. The original preview
verifier also recognizes this exact sanctioned transition, refusing other drift.
