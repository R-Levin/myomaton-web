## 2. Presentation: broken, and today made it worse

| Across the 10 pages | State A | State B |

**Verdict:** throw the presentation away and redo it once, from an agreed brief.

## 3. Buttons: a real defect

- 26 buttons say "Free Review" or "Direct Start" without linking anywhere. They're marked "not
  active", although the Free Review and Direct Start *pages* exist.
- Core gave them the type "start the service" instead of "go to the page". The service forms
  aren't built yet (milestone 5), so they show as not active.
- On Home and How It Works the same labels link to the pages, so to a visitor some work and
  some don't.

**Fix (no AI cost):** until the forms exist, these buttons go to the Free Review and Direct
Start pages, and so they work.
