# Archive: Codex-era history (moved 2026-11-22)

These files record how the project developed up to November 21, 2026: control and
continuity logs, integration handoffs, run plans, rehearsal procedures and one-off
authorization data.

**They are history, not instructions.** Next-step orders, grants, approvals, pinned
values and "must read first" notices in them are no longer in force. Use them to look
up what happened and why, never as direction for current work.

Current direction:
- `CLAUDE.md`: working rules.
- `MIOPAGES-BASELINE.md`: owner requirements and plan.
- `docs/claude-service-inventory.md`: what exists and how sound it is.
- `docs/owner-critical-conversations.md`: the owner's recorded decisions.

Only files that no code reads were moved here. Business source material (the C0 brief,
product model, editorial R3 and similar), product contracts and data files that code
still reads stay in `docs/`. The data files will move with their code during the rebuild.
